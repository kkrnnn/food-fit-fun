# Food Fit Fun — ไอเท็มเดี่ยวคละและผล BMI

วันที่: 2026-10-03 · พัฒนาใน local แล้ว ยังไม่ deploy

เอกสารนี้แทนกติกา layout/อาหาร/พลาดมื้อ/ปุ่มกระโดดของแผน exercise ก่อนหน้า ตามคำขอล่าสุด

- 30 จุดต่อรอบ จุดละ 1 ไอเท็ม สุ่มชนิดด้วย shuffled bag, เลนและระยะมี seed; ไม่วางคู่ตัวเลือกสองชิ้นในแถวเดียว
- 5 จุดออกกำลังกายอยู่กลางช่วงระหว่างคำถาม สุ่มช่วงจาก 2–9 และคละชนิด ไม่ใช้ตำแหน่งชุดเดิมทุก seed
- อาหารดีลด balance 4 จุด; ผัก/มื้อสมดุลลด 6; ออกกำลังกายลด 20; เครื่องดื่มกลาง 0; ของหวาน/อาหารเดิมเพิ่ม 18–28 ตาม catalog
- ของดีลดจริงทั้งด้านบวกและลบ ไม่คืนค่าลบเข้าหา 0 เหมือนก่อน แต่ยัง clamp ±100; BMI จริงของโปรไฟล์ไม่ถูกแก้
- เก็บพลาดทุกประเภทไม่เปลี่ยน BMI ไม่มี missed meal penalty/event
- แยก `isExercise` จากทิศผล BMI เพราะอาหารดีและ exercise ลดค่าเหมือนกัน แต่อาหารเก็บบนพื้น ไม่ต้องกระโดด
- ของออกกำลังกายยกตำแหน่ง model จาก 2.2 เป็น 3.8 เหนือพื้น; ยังต้องอยู่เลนเดียวกันและมี jump action
- ไม่มี pickup popup BMI ± หรือปุ่มกระโดด คงการกระโดดด้วยกล้อง Space/↑ และ swipe ขึ้น เสียง/particles และแถบ BMI หลักยังอยู่
- บทฝึกแสดงผลอาหารลด 4 และกระโดดลด 20 ตามกติกาจริง; หน้าอธิบายการเล่นไม่อ้างว่าพลาดมื้อแล้วมีโทษ
- เปลี่ยน level/body version เพื่อไม่ปนคะแนนต่างกติกา

## ตรวจรับ

- `npm run test`: 78/78 ผ่าน ใน 16 files
- `npm run build`: ผ่าน มี bundle size warning เดิม
- `git diff --check`: ผ่าน
- สุ่ม 50 seeds: ไอเท็มครบ 15 ชนิด, มีชนิด exercise 5 จุด, ระยะไม่ซ้ำ (จุดละหนึ่งชิ้น), gap อย่างน้อย 2 วินาที, กัน quiz approach, layouts และตำแหน่ง exercise ต่างกันระหว่าง seeds
- Session tests: อาหารลดน้อยกว่า exercise, clamp, ไม่เปลี่ยน profile, ไม่เก็บพลาดแล้วลด BMI, exercise ต้องกระโดด, pause ยกเลิก jump เดิม
- Browser local: ตรวจ DOM ว่าไม่มีปุ่มกระโดดและ pickup popup; รอบยังจบเมื่อผิดติดกัน 3 ข้อได้; ตรวจฉากไอเท็มเดี่ยวจาก UI
