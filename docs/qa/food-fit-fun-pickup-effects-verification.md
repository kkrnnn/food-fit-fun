# Food Fit Fun — เอฟเฟกต์รับไอเท็มรอบตัว

วันที่: 2026-10-03 · Local เท่านั้น ยังไม่ deploy

ตามคำยืนยันล่าสุด ไม่มี popup, ป้าย, สัญลักษณ์ หรือข้อความใหม่เหนือหัว มีเฉพาะแสง/ประกายรอบตัว เกจ BMI และ quiz feedback คงเดิม

- อาหารดี: วงเขียวกลมขยายและประกายกลมพุ่งขึ้น 32 จุด
- ของที่เพิ่ม BMI: วงส้มแดงทรงหกเหลี่ยม pulse และประกายตกลง 24 จุด
- ตัวเลือกกลาง: วงและประกายฟ้า 16 จุด ไม่แสดงเป็นอาหารดี
- ออกกำลังกาย: วงเขียว 42 จุด พร้อมวงทองที่เท้าเพิ่มอีกชั้น
- ยืดเอฟเฟกต์หลักเป็น 1.05 วินาที เพิ่มขนาดประกายและความหนาวง ใช้ particle texture กลมที่มีอยู่ แยกออกจากเอฟเฟกต์ quiz
- Reduced motion: มีวงสีเพื่อสื่อผล แต่ไม่ปล่อยประกายและไม่ขยาย/pulse วง
- ใช้ session events เดิม จึงไม่เล่นซ้ำจาก React render; จำกัดเอฟเฟกต์ค้างสูงสุด 8 ชุดตามระบบเดิมและ dispose resources เมื่อหมดอายุ
